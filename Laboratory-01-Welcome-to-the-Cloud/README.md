Mission Overview
Congratulations!
You have been accepted as a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, a
company specializing in cloud infrastructure, virtualization, and enterprise cloud solutions.
As part of your onboarding process, you must complete your first mission. Before deploying cloud services or
managing enterprise infrastructures, every cloud engineer must first learn how to work inside a Linux
environment, document their work professionally, and maintain a version-controlled portfolio using GitHub.
Your task is to complete the onboarding mission using the KillerCoda Playground and create your personal
Cloud Computing Portfolio on GitHub. This portfolio will serve as your professional workspace throughout the
semester and will be updated after every laboratory activity.
Complete each checkpoint carefully. Every completed task represents a real-world responsibility of a cloud
engineer.
Mission Objectives
Upon successful completion of this mission, you should be able to:
 Access a cloud-based Linux environment using KillerCoda.
 Explore and navigate the Linux operating system.
 Gather basic system information.
 Organize files and directories using Linux commands.
 Create and maintain a professional GitHub repository.
 Document technical work using Markdown.
 Demonstrate proper documentation practices used by cloud professionals

Activities Performed
Throughout this onboarding mission, the following practical tasks were completed:
 Launched and accessed an interactive cloud-based Ubuntu environment via KillerCoda.
 Navigated through the Linux file system hierarchy to inspect system structures.
 Executed diagnostic commands to retrieve hardware, OS, and system information.
 Performed file management tasks including creating, modifying, and moving directories and files.
 Initialized a Git repository and published initial laboratory documentations to GitHub.

Linux Commands Used
Key terminal commands utilized during the laboratory session include:
 Navigation & Inspection: `pwd`, `ls`, `cd`
 System Diagnostics: `uname`, `hostname`, `whoami`
 File & Directory Management: `mkdir`, `touch`
 Text Processing & Viewing: `cat`, `nano`

Skills Learned
By finishing this onboarding process, core technical competencies gained include:
 Command Line Interface (CLI) Fluency: Comfortable working in headless, cloud-hosted Linux environments.
 Directory Management & Operations: Ability to structure and manipulate project files efficiently via terminal.
 System Analysis: Knowledge of inspecting underlying hardware and OS details using basic shell utilities.
 Technical Documentation: Ability to present lab workflows clear and organized using Markdown syntax.
 Version Control Fundamentals: Experience tracking work progress and syncing local changes to GitHub.
