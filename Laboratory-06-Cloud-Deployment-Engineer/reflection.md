# My Reflection

This laboratory activity helped me understand how Docker Compose makes application deployment simpler and more organized. Instead of entering commands for each container separately, I was able to place their configurations in one `docker-compose.yml` file. This saved time and allowed me to start multiple services together using just one command.

I also learned how important proper YAML indentation is when creating configuration files. Even a small mistake, such as using a Tab instead of spaces or placing a line in the wrong section, can cause errors. Because of this, I realized that I need to pay close attention to the file's structure and check the indentation before running any commands.

Another important lesson was understanding how environment variables work. Settings such as `MYSQL_PASSWORD` and `MYSQL_DATABASE` provide the necessary information for configuring MariaDB and connecting it to Nextcloud. I now have a better understanding of how these values help the two services communicate with each other.

One of the most interesting parts of this activity was seeing how Nextcloud and MariaDB work together to create a private cloud storage system. At first, the configuration seemed a little confusing, but as I understood the purpose of each service, the process became easier to follow. It was satisfying to see how a few commands and a configuration file could be used to set up a working application.

Since Mission 1, my knowledge of Cloud Computing has gradually improved. Before, I mainly associated it with storing files and accessing online services. Now, I understand that it also involves managing infrastructure, running containers, connecting applications, and automating deployment tasks. I know there are still many things I need to learn, but this laboratory gave me more experience with cloud technologies and made me more confident in performing these tasks independently.
