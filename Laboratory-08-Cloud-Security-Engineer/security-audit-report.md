# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions and access they need to perform their assigned tasks. This helps improve security by preventing unauthorized access to important files, applications, and system resources. It also reduces the chances of users accidentally making changes that could affect the system.

## 2. Attack Surface

The attack surface refers to all the possible entry points that an attacker could use to access or compromise a system. These may include open network ports, running applications, and services with security vulnerabilities. Reducing unnecessary ports and disabling unused services can help minimize security risks and make the server more difficult to attack.

## 3. Default Deny Policy

A Default Deny Policy is a firewall setting that blocks all incoming network connections unless they are specifically permitted by an existing rule. This approach provides better protection because it prevents unknown or unauthorized connections from reaching the server. By allowing only trusted and necessary traffic, we can reduce potential security threats and maintain better control over network access.

## Summary

Through this security audit, I learned the importance of controlling user permissions, reducing unnecessary entry points, and managing network traffic through firewall rules. These security practices help protect servers from unauthorized access and make cloud infrastructure more secure and reliable.
