# Automation Research: The Language of Automation

## 1. Bash Script

A Bash script is a file that contains a series of Linux commands that can be executed automatically in order. Instead of typing each command one by one, we can place them inside a single script to make repetitive tasks easier and faster. The `#!/bin/bash` line at the beginning is called a shebang, which tells the system to use Bash when executing the script.

## 2. Variables

Variables are used to store information that can be reused throughout a script. For example, `$BACKUP_DIR` can store the location of a backup folder so we do not have to repeatedly type the same directory path. Using variables also makes scripts easier to read, maintain, and update whenever changes are needed.

## 3. Cron Job

A cron job is a Linux feature that allows commands or scripts to run automatically at scheduled times or regular intervals. It is especially useful in cloud operations because it can handle repetitive tasks, such as creating backups and performing routine maintenance, without requiring someone to execute them manually each time.

## Summary

Through this research, I learned how Bash scripts, variables, and cron jobs work together to make Linux automation possible. These tools help simplify repetitive tasks, save time, and make system administration more organized and efficient.
