## 💭 My Reflection

Completing this laboratory activity helped me understand how automation makes cloud management more efficient and reliable. When managing hundreds or even thousands of cloud servers, performing tasks manually can take a lot of time and increase the chances of human error. By using scripts and scheduled tasks, administrators can automate repetitive activities, such as creating backups, without having to enter the same commands repeatedly.

I also realized that automation needs to be handled carefully because mistakes can affect multiple systems. For example, a small error in a script running across hundreds of servers could accidentally delete important files or cause unexpected problems. This is why scripts should always be reviewed and tested before being used in a larger environment.

One thing I found interesting was the difference between writing a Bash script and creating a Docker Compose YAML file in Mission 6. In Bash scripting, I used commands to perform tasks in a specific order, such as creating directories and compressing application data. Meanwhile, Docker Compose uses YAML to define and manage multiple services and their configurations. Although both tools help simplify cloud operations, they have different purposes.

Looking back at my GitHub repository from Laboratory 1 to Laboratory 9, I can see how much my understanding of cloud computing has improved. At first, I was mostly learning about basic Linux commands and cloud infrastructure. As I continued completing the activities, I gained experience with containers, storage, deployment, system monitoring, security, and automation. I now understand that cloud computing is not just about running applications but also about managing, maintaining, and protecting the systems behind them.

Among all the roles I explored, I enjoyed being a **Cloud-Native Engineer** the most because I found working with Docker and containers interesting. I liked learning how applications can run in isolated environments and how containers make deployment and management easier. This experience made me more interested in learning about container technologies and how they are used in real-world cloud environments.

Overall, these nine laboratory activities gave me valuable hands-on experience and helped me understand the different responsibilities of a cloud engineer. I know there is still a lot more to learn, but I am happy with the progress I have made and the knowledge I have gained throughout this course.
